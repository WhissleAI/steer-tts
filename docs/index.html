SteerTTS

A small English text-to-speech model you can steer with numbers, style tags, free-text prompts and inline markup. Every clip below is raw model output, with no cherry-picking across seeds.

  • SteerTTS edge (12 MB)
  • C library (no Python)

The same models in plain C

One C11 library, no dependenciesboth models, every feature27 MB RAM for edge1.4 MB static binary

The C library runs v1 (flow refiner, free-text prompts, voice cloning, fp32 or int8) and the edge build without Python, PyTorch or ONNX Runtime. Same requests, same audio: on 218 test sentences the C renders have exactly the same length as the Python ones and differ from them by about 0.0001 dB in the spectrum.

Try it

pip install "steertts[all] @ git+https://github.com/WhissleAI/steer-tts"

steertts say "Hello there, nice to meet you." -o hello.wav

The v1 weights download from Hugging Face on first use. The repo asks you to accept the licence terms once (CC BY-NC 4.0).

Without Python, with the C library:

git clone https://github.com/WhissleAI/steer-tts && cd steer-tts/c
make                                    # or: cmake -B build && cmake --build build
tools/get_models.sh edge                # 13 MB (export HF_TOKEN=... if the repo asks you to accept its licence)
build/steertts --model models/steer-tts-edge "Hello from C." -o hello.wav
